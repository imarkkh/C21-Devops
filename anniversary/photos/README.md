# 📸 Drop your photos here!

Put all your pictures in **this folder** and they will automatically show up
on the website — you never need to edit any code (or use any AI credits 😉).

## How to add photos (easiest way — on github.com)

1. Open this `anniversary/photos/` folder on github.com
2. Click **Add file → Upload files**
3. Drag & drop as many photos as you want
4. Click **Commit changes**
5. Refresh the website — they're live! 🎉

Any filename works when the site is hosted on GitHub Pages
(`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`). Photos appear sorted by filename,
so if you want a specific order, name them `01-...`, `02-...`, etc.

## If you open index.html directly on your computer

When viewing the page locally (double-clicking `index.html`), name the photos
with numbers so the page can find them:

```
1.jpg  2.jpg  3.jpg  4.png  5.jpg  ...
```

Numbering must be consecutive starting at 1 — the page stops looking at the
first missing number.

## Tip: keep photos small

Phone photos can be 5–10 MB each. The site loads much faster if you resize
them first (e.g. with https://squoosh.app — free, works in the browser).
Around 1600px wide / under 500 KB per photo is perfect.
